Problem statement:
Develop a web-based interactive 3D visualization platform that integrates numerical ocean model outputs and in-situ observations.
Explanation:
India's ocean agency (INCOIS) has two kinds of ocean data — computer predictions (models) and real measurements from floating robot sensors (Argo floats, Gliders). Right now, there's no single website where you can see both together in 3D. Scientists use different tools, and most only show flat 2D maps, not real depth.
What Needs to Be Built:
A website (works in any browser, no download needed) that:
Shows the ocean in true 3D — you can rotate, zoom, and see different depths
Shows sensor locations as clickable dots — click one to see a graph of temperature/salinity at that spot
Lets
 users switch between variables (temperature, salinity, currents), slide through depth, and animate through time
Can be expanded later to add new sensors or data types

Main problems with existing solutions
Data is not fully integrated – Model data and real instrument observations may not be shown together smoothly.
Model vs real-data comparison is limited – Comparing a model value with an Argo/Glider observation at the same depth, location and time is not the main workflow.
Some tools are desktop-based – They may require software installation.
Not specifically designed for INCOIS – Existing platforms are general-purpose.
Complex for some users – Scientific tools can require technical knowledge.
Different data sources/tools – Scientists may need multiple systems for different datasets.
